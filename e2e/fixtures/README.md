# DOCX 回归样本

这些样本由 `python3 scripts/build_regression_docs.py` 使用 Python 标准库生成，固定 ZIP 时间戳，可重复生成。它们用于检查已知 OOXML 结构，经代码核对预期；不是 Word、WPS 或 LibreOffice 实际导出的文档，也不代替人工审阅及真机检查。

| 文件对                                        | 明确预期                                                                                                              | 支持边界                                                       |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| clauses                                       | 金额 100000→120000、日期 9 月→10 月、比例 0.05%→0.08%、不得→可以、3 日→7 日，五处均应标记；两处重复的履约记录段落不变 | 只比较内容，不依赖页码或字体                                   |
| unicode                                       | emoji 和补充平面字符替换标记完整字符；组合 emoji 保持原样；波斯语连接控制符的删除应报告差异                           | 检查字符保真和高亮边界，不依赖系统字体的字形覆盖               |
| structure-images                              | 保留 colspan=2、rowspan=2；合并表格内金额变更应标记；三幅重复付款图依次为字节相同、相同像素重新编码、第四根柱高度变化 | 重编码仍是图片差异；不同字节的相似度上限为 99%，不代表改动面积 |
| tracked                                       | 原稿为“15 日”；修订稿仍带“删除 30 日、插入 15 日”；按接受修订状态比对后无内容差异，并说明修订处理方式                 | 不做修订记录历史对比                                           |
| native-chart                                  | 正文相同，原生图表数值不同；正文零差异结果必须限定范围，两侧各报告一个未覆盖图形                                      | 原生图表的图表数据尚不参与比较                                 |
| tracked-aliased / native-chart-aliased        | 使用 `word` 前缀代替 `w`；修订说明和图表未覆盖提示应与对应原样本一致                                                  | 命名空间别名不改变内容语义；由 XML 序列化器重新命名前缀        |
| hash-collision                                | 正文相同，红色 PNG 改为蓝色 PNG；两幅图片长度和旧版 FNV-1a 哈希相同，禁用 Web Crypto 后仍应报告图片差异               | 有效 PNG，SHA-256 指纹不同；复现短哈希导致的图片漏报           |
| table-boundary                                | 数量/单价从 `[1, 23]` 改为 `[12, 3]`，两格均高亮，同一行作为审阅单元                                                  | 忽略空白开启或关闭时都必须检出，不能只标记单元格分隔换行       |
| confidential                                  | 两次重复的保密条款期限均从 1 年改为 3 年，开启版面过滤仍保留两处正文变化                                              | 正文保密关键词与重复次数不能单独作为过滤证据                   |
| link / superscript / line-break               | 链接目标改变、普通 `m2` 改为上标、`A` 与 `B` 之间删除显式换行，均可定位和审阅                                         | 链接与上下标不改变文本相似度；英文单词分隔仍有意义             |
| long-table-semantic                           | 长表格单元格同时修改两端文字与中间的链接目标，粗略文字修复后仍保留链接语义，且不嵌套高亮                              | 超过单元格精确修复长度上限；实际导入后检查文本和标记完整性     |
| image-moved                                   | 唯一且字节不变的图片从第 1 条后移到第 2 条后，作为一处图片移动报告                                                    | 不依赖多幅图片之间的顺序变化                                   |
| empty-body / header-only / blank              | 页眉不参与正文；一侧无正文、两侧仅页眉或两侧空白文档都能结束比较并展示结果，不反复重算                                | 空正文是合法成功结果，提示文字不能进入比较输入                 |
| layout-only                                   | 正文只有页码，开启过滤后两侧皆为空，仍展示一次已完成结果和两处版面过滤明细                                            | 过滤产生的空 HTML 也不能作为未比较的标志                       |
| large-image                                   | 10000×4100 的有效 PNG 超过单图预算，不创建可加载的图片 URL、不解码或预览；原始字节指纹仍参与比較                      | 小体积 DOCX 也可能含高像素图片；不在测试中主动解码此图         |
| large-image-svg-filter / large-image-svg-html | SVG 滤镜中嵌入同一超大 PNG，或使用含该 PNG 的 HTML 子内容，均不能创建可加载源、解码或预览，仍比较原始字节             | SVG 外层尺寸小也不能掩盖内嵌资源；HTML 子内容按无法验证处理    |

真实文档补充时需登记编辑器和版本、来源及授权、脱敏方式、人工确认的预期差异和检查人。当前这部分仍待补充。浏览器自动化中的手机项目是视口和触摸模拟；实体设备仍需抽查导入、定位、图片缩放及旋转。
