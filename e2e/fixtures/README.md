# DOCX 回归样本

这些样本由 `python3 scripts/build_regression_docs.py` 使用 Python 标准库生成，固定 ZIP 时间戳，可重复生成。它们用于检查已知 OOXML 结构，经代码核对预期；不是 Word、WPS 或 LibreOffice 实际导出的文档，也不代替人工审阅及真机检查。

| 文件对           | 明确预期                                                                                                              | 支持边界                                                       |
| ---------------- | --------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| clauses          | 金额 100000→120000、日期 9 月→10 月、比例 0.05%→0.08%、不得→可以、3 日→7 日，五处均应标记；两处重复的履约记录段落不变 | 只比较内容，不依赖页码或字体                                   |
| structure-images | 保留 colspan=2、rowspan=2；合并表格内金额变更应标记；三幅重复付款图依次为字节相同、相同像素重新编码、第四根柱高度变化 | 重编码仍是图片差异；不同字节的相似度上限为 99%，不代表改动面积 |
| tracked          | 原稿为“15 日”；修订稿仍带“删除 30 日、插入 15 日”；按接受修订状态比对后无内容差异，并说明修订处理方式                 | 不做修订记录历史对比                                           |
| native-chart     | 正文相同，原生图表数值不同；正文零差异结果必须限定范围，两侧各报告一个未覆盖图形                                      | 原生图表的图表数据尚不参与比较                                 |

真实文档补充时需登记编辑器和版本、来源及授权、脱敏方式、人工确认的预期差异和检查人。当前这部分仍待补充。浏览器自动化中的手机项目是视口和触摸模拟；实体设备仍需抽查导入、定位、图片缩放及旋转。
